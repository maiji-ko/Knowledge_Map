函数模板的参数推导(Template Argument Deduction) 是编译器在 **不显式指定模板参数** 时，根据 **函数调用时传入的实参**，自动推断出模板类型参数的过程。
**核心认知**：`auto` 的类型推导规则 **完全基于** 函数模板的参数推导规则。

---
### 一、基本推导机制：P 与 A 的匹配
编译器推导时，主要做两件事：
- P(Parameter)：函数形参的类型 (包含模板参数，如 `T`、`const T&`)
- A(Argument)：函数实参的类型
推导的目标是：**找到模板参数**`T`，**使得替换后的**`P`**能够与**`A` 匹配
``` c++
template<typename T>
void foo(T param); // P = T

int x = 42;
foo(x); // A = int -> T 被推导为 int
```

---
### 二、三大核心推导规则
根据函数形参 `P` 的"形式"，推导分为三种情况。这是整个推导机制的骨架。
**情况一**：**形参是值类型** (`T`/`const T`/`volatile T`)
- **规则**：忽略实参的 **顶层**`const`、顶层 `volatile` 和 **引用** (发生类型退化，Decay)
- **数组退化为指针**，函数退化为函数指针

| 函数实参 (P)  | 传入实参 (A)        | 推导出的 `T`                 | 实例化后的形参类型                  |
| --------- | --------------- | ------------------------ | -------------------------- |
| `T`       | `int`           | `int`                    | `int`                      |
| `T`       | `const int`     | `int` (丢弃 const)         | `int`                      |
| `T`       | `int&`          | `int` (丢弃引用)             | `int`                      |
| `T`       | `const int&`    | `int` (丢弃 const 和 引用)    | `int`                      |
| `T`       | `const char[5]` | `const char*` (数组退化为指针)` | `const char*`              |
| `const T` | `int`           | `int`                    | `const int` (保留了形参的 const) |
``` c++
template<typename T>
void f(t param);

const int a = 10;
f(a); // T = int, param 是 int (拷贝了一份，原始 a 的 const 被忽略)

int b = 20;
int& ref = b;
f(ref); // T = int, param 是 int (引用被忽略)
```
**情况二**：**形参是左值引用** (`T&` / `const T&`)
- **规则**：传入的实参必须是 **左值**
- **不忽略** `const` (引用不能丢弃底层常量性)
- **数组不会退化为指针** (数字引用绑定的仍是整个数组)

| 函数形参 (P)   | 传入实参 (A)        | 推导出的 `T`        | 实例化后的形参类型                             |
| ---------- | --------------- | --------------- | ------------------------------------- |
| `T&`       | `int`           | `int`           | `int&` (但右值 `int` 不能绑定左值引用，编译失败)      |
| `T&`       | `int&`          | `int`           | `int&` (引用折叠)                         |
| `T&`       | `const int`     | `const int`     | `const int&` (保留 const)               |
| `const T&` | `int`           | `int`           | `const int&` (可绑定右值，常量左值引用有延长生命周期的能力) |
| `T&`       | `const char[5]` | `const char[5]` | `const char (&)[5]` (数组引用，不退化)        |
``` c++
template<typename T>
void f(T& param);

int x = 5;
const int cx = 10;
f(x); // T = int, param 类型为 int&
f(cx); // T = const int, param 类型 const int& (cx 的常量性被保留)
f(5); // 编译错误：无法将右值绑定到非常量左值引用
```
**情况三**：**形参是万能引用** (**转发引用**) (`T&&`)
- **规则**：如果实参是 **左值**，`T` 推导为 **左值引用** (触发引用折叠，最终形参是左值引用)
- 如果实参是 **右值**，`T` 推导为 **非引用类型** (形参是右值引用)
> **口诀**：左值变 `T&`，右值变 `T`

| 函数形参 (P) | 传入实参 (A)         | 推导出的 `T`     | 实例化后的形参类型 (折叠后)                 |
| -------- | ---------------- | ------------ | ------------------------------- |
| `T&&`    | `int` (左值)       | `int&`       | `int&&` -> `int&`               |
| `T&&`    | `const int` (左值) | `const int&` | `const int& &&` -> `const int&` |
| `int&&`  | `int` (右值)       | `int`        | `int&&`                         |
``` c++
template<typename T>
void f(T&& param); //  万能引用 (仅在 T 是模板参数且形参是 T&& 时)

int x = 10;
f(x); // 左值 -> T = int&, param = int&
f(10); // 右值 -> T = int, param = int&&
```

### 三、特殊推导场景
#### 3.1 初始化列表 (`std::initializer_list`)
- 推导时，`std::initializer_list` 不会自动转换
- `auto` **特例**：`auto a = { 1, 2, 3 };` 会推导为 `initializter_list`，但函数模板默认 **不能** 从 `{1, 2, 3}` 推导 `T` (除非形参明确是 `std::initializer_list<T>`)
``` c++
template<typpename T>
void f(t param);
f({1, 2, 3}); // 编译错误：无法推导 T

template<typename T>
void g(std::initializer_list<T> list);
g({1, 2, 3}); // 正确，T = int
```
#### 3.2 函数名与重载集
如果实参是函数名或重载函数，编译器通常无法推导，除非显式转换
``` c++
void func(int);
void func(double);

template<typename T>
void call(T t);
call(func); // 错误：重载集不明确
```
#### 3.3 默认模板参数不参与推导
模板的默认类型参数 (如 `template<typename T = int>`) 仅在 **无法推导** 或 **未提供** 时使用
``` c++
template<typename T = int>
void f(T x);
f(3.14); // T 推导为 double, 默认值被忽略
f(); // 编译错误 (无实参，无法推导)，除非有默认参数且显式指定 <>
```

### 四、推导过程中允许的隐式转换 (非常有限)
为了安全，C++在模板推导时 **拒绝一般隐式转换**。仅在以下三种情况下接受转换：
1. **左值转右值** (如将左值传给 `T` 值参数，即拷贝)
2. **数组**/**函数退化为指针** (如传数组名给 `T`)
3. **CV限定符移除** (如 `const int` 传给 `T` 变成 `int`)
4. 除此之外，任何其他类型转换 (如 `short` 转 `int`、`派生类指针` 转 `基类指针`) 都会导致 **推导失败**，编译器会报错
``` c++
template<typename T>
void f(T param);

short s = 5;
f(s); // 推导 T = short (不会提升为 int)，如果希望 int，需显式 f<int>(s);
```

---
### 五、多重参数推导规则
当函数有多个模板时，每个参数独立推导，但推导出的类型必须 **一致**
``` c++
template<typename T>
void f(T a, T b);

f(10, 3.14); // 错误：第一个推导为 int，第二个推导为 double，类型冲突
```
如果希望允许不同类型，可以声明不同的模板参数：
``` c++
template <typename T, typename U>
void f(T a, U b); // 允许 int 和 double 混用
```

### 六、总结速查表 (对比 [[auto 和 decltype | auto]])

| 形参形式 (P)                   | 实参类型        | 推导出的 `T` (或 `auto`) | 实际参数类型            |
| -------------------------- | ----------- | ------------------- | ----------------- |
| `T` / `auto`               | 左值/右值/const | **值类型**(退化)         | 丢弃引用、const、数组     |
| `T&` / `auto&`             | 左值          | **非引用**             | 左值引用 (保留 const)   |
| `const T&` / `const auto&` | 左值 /右值      | **非引用**             | 常量左值引用 (保留 const) |
| `T&&` / `auto&&`           | 左值          | `T&`                | 左值引用 (折叠)         |
| `T&&` / `auto&&`           | 右值          | `T`                 | 右值引用              |

### 七、实战：结合 `std::forward` 的完美转发 (理解推导的现实意义)
``` c++
template<typename T>
void wrapper(T&& arg) {
    // 判断传入的是左值还是右值
    // 如果传入左值 int，T = int&, forward 会保留左值属性
    // 如果传入右值 int，T = int, forward 会转为右值
    process(std::forward<T>(arg));
}
```
这就是 **引用折叠** 和 **左值**/**右值推导规则**的经典应用 -- 完美转发

### 八、常见面试陷阱速答
- **问**：`template<typename T> void f(T param);` 传入 `const char* const`，`T` 是什么？
**答**：`const char*` (顶层 `const` 被忽略，但指针指向的 `const char` 不会被忽略，因为不是顶层)
- **问**：`template<typename T> void f(T& param);` 传入 `int arr[10]`，`T` 是什么？
**答**：`int[10]` (数组引用不退化，`param` 为 `int (&)[10]`)
- **问**：`template<typename T> void f(T&& param);` 传入 `const int&&` (右值常量)，`T` 是什么？
**答**：`const int` (右值不触发左值引用推导，保留底层 const，形参为 `const int&&`)

---
### 总结
函数模板参数推导的核心是 **看形参的**"**样子**“
- **值传参**(`T`)：无情丢失一切修饰和引用，只保留本体
- **左值引用**(`T&`)：保留常量性，数组不变
- **万能引用**(`T&&`)：左值变 `T&`，右值变 `T` (完美转发基石)
掌握了这三条，你不仅掌握了模板推导，更从根本上理解了 `auto` 和 `decltype(auto)` 的行为逻辑。这对于编写泛型代码 (尤其是库作者) 至关重要。
