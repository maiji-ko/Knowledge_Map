### 一、是什么
C++异常处理是C++语言提供的一种错误处理机制，允许程序在运行出现错误时，通过 `try`、`catch`和`throw`三个关键字将错误信息传递回调用栈，进行异常处理。
简单来说，当程序检测到无法处理的错误时，可以 **抛出** 一个异常对象；程序的控制流会沿着调用栈向上回溯，直到找到能够 **捕获** 并处理这个异常的代码；如果始终没有找到，程序将终止。
C++的异常处理机制支持异常的重新抛出、自定义异常体系，并且标准库提供了以 `std::exception` 为基类的异常类层次结果。

### 二、为什么需要它
#### 2.1 传统错误处理方式的缺陷
在C语言中，错误处理主要依赖两种方式：`assert` 终止程序，或返回错误码。这些方式存在明显问题：
- **容易忽略错误检查**：调用方可能忘记检查返回值，导致程序在错误状态下继续运行，产生不可预知的结果
- **错误信息不充分**：仅凭一个错误码难以传递足够的上下文信息，调试困难
- **代码可读性差**：大量的错误码检查逻辑混杂在正常业务逻辑中，干扰代码的清晰度
#### 2.2 异常处理的核心优势
- **强制处理错误**：未捕获的异常会终止程序，迫使开发者必须正视错误
- **分离错误检测与处理**：异常可以在检测错误的代码与处理错误的代码之间建立明确的分离，中间函数可以透明地让异常传播
- **自动资源清理**：异常抛出后，栈展开机制会自动销毁沿途的所有局部对象，确保资源被正确释放
- **信息丰富**：异常是对象，可以携带详细的错误描述和上下文信息

### 三、核心语法与分类
#### 3.1 三个核心关键字
| 关键字     | 作用                                               |
| ------- | ------------------------------------------------ |
| `try`   | 标记一个可能抛出异常的代码块，其中的代码被称为"保护代码"                    |
| `throw` | 抛出一个异常对象。当问题出现时，程序通过 `throw` 来发出异常信号             |
| `catch` | 捕获 `try` 块中抛出的异常并进行处理，可以有多个 `catch` 分支来匹配不同类型的异常 |
