# C++ 三周每日提示词（可直接复制）

## 使用说明

- 每天复制对应代码块，直接发送到 DeepSeek 网页端。
- 代码块内已包含“手敲优先、禁止代写”的生成限制，不需要额外补充规则。
- 代码块之外的“本地记录”不要发送；每天完成后自行填写。
- 若 DeepSeek 输出完整实现，回复：`停止，只给提示、检查点和验收标准，不要给完整实现。`
