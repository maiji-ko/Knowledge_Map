# C++ 三周学习大纲

## 一、三周目标

- **第 1 周目标**：建立单文件 C++ 程序的完整认知，能独立完成基础语法、类型与运算符、控制流、函数、数组与字符串、指针与引用、动态内存、结构体与枚举的手敲练习，并能定位常见编译与运行错误。
- **第 2 周目标**：掌握面向对象与资源管理，能设计带封装、构造与析构、继承与多态、运算符重载、模板、异常处理、文件 IO、RAII 的类与小型模块。
- **第 3 周目标**：掌握 STL 容器、迭代器、算法、智能指针、移动语义、Lambda、现代 C++ 特性、多文件编译链接与调试，并完成一个可验收的小型项目。
- **总产出**：21 份手敲练习、21 篇按模板整理的笔记、1 个小型项目、1 份持续更新的知识点索引。
- **时间预算**：合计约 67.5 小时，单日 2.5—5 小时；可按基础上下浮动约 20%。
- **每日闭环**：阅读当日提示词 → 手敲练习 → 自测 → 填写每日记录 → 更新索引掌握状态。
- **总体验收**：代码可构建、边界用例可复现、错误能解释、笔记可追溯、索引状态与实际掌握一致。
