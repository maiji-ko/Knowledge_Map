# C++ 知识点索引

## 一、命名与状态规则

- 每日笔记使用独立目录：`notes/DayNN/`。
- 主笔记固定为：`notes/DayNN/笔记.md`。
- 每日笔记总目录：`notes/README.md`。
- 同一天有多个知识点时，共用当日 `笔记.md`，并在笔记的知识点 ID 中全部列出。
- 手敲文件建议放在 `code/DayNN/` 下，文件名体现任务，不在此处生成任何代码内容。
- 掌握状态取值：未开始、进行中、已掌握、需复习。
- 每日结束后同步更新笔记 frontmatter 与本表状态；自测失败或复盘有缺口时标记为需复习。
